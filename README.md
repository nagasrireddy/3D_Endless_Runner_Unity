# 🎮 3D Endless Runner

## 📌 About the Project
3D Endless Runner is an arcade-style endless running game developed using **Unity 3D and C#**. The player runs continuously through the game environment, avoiding obstacles and trying to achieve the highest possible score.

## ✨ Features
- 3D game environment
- Player movement and running mechanics
- Obstacle avoidance
- Coin collection
- Score tracking
- Interactive gameplay
- Game over and restart functionality

## 🛠️ Technologies Used
- Unity 3D
- C#
- Visual Studio
- TextMeshPro

## 🎮 Controls
- **A / Left Arrow:** Move Left
- **D / Right Arrow:** Move Right
- **Spacebar:** Jump

*Update these controls if your game uses different keys.*

## 🚀 How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/nagasrireddy/3D_Endless_Runner_Unity.git
   ```
2. Open Unity Hub.
3. Click **Add → Add project from disk**.
4. Select the downloaded project folder.
5. Open the project using the compatible Unity version.
6. Open the main game scene.
7. Click the **Play** button.

## 🎯 Project Objective
The objective of this project is to develop an engaging 3D endless runner game while learning Unity game development, C# scripting, player movement, collision detection and game mechanics.
